## 📝 1. Descripción del Proyecto
Este repositorio contiene el código fuente del **Trabajo Práctico N.º 2**, el cual representa la migración y evolución de nuestro portfolio grupal desde una arquitectura estática (HTML/CSS/JS Vanilla del TP1) hacia una aplicación moderna de página única (**SPA**) desarrollada en **React** utilizando **Vite** y **React Router**. 

El sitio cuenta con una estructura modular compartida mediante una **Sidebar fija**, gestión de perfiles individuales actualizados a React, un sistema local con 20 registros temáticos equipados con búsqueda y filtros interactivos, consumo dinámico de una API pública con gestión de estados (carga, éxito y error), y documentación técnica integrada.
